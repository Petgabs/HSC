Cloud Settings

Master password required

Enter the master password to open Cloud Settings, including GitHub access and administrator account controls.

This is not the administrator sign-in password. You must enter it each time you open Cloud Settings.

Save the token once as the private SCHOOLCLOUD_PUBLISH_TOKEN GitHub Actions repository secret. GitHub encrypts it; the token is never written as plaintext to a repository file or website asset. This static website cannot read GitHub secret values back, so the token you connect here is also saved in this browser's storage on this device. Save it once and the dashboard reconnects on its own after a reload, a new tab or the next sign-in.

GitHub repository

Uploads are committed into apps/ and their metadata is added to library.json. GitHub Pages then publishes the files for students.

GitHub upload access

Use a fine-grained Personal Access Token scoped to this repository with Contents: Read and write and Secrets: Read and write.

On save, the token is encrypted with GitHub's repository public key and stored as a private Actions secret; if that secret already exists it is left unchanged. The token is also saved on this device, so you only paste it once.

Connected.

Direct publishing is enabled. This token is saved on this device, so signing out, closing the tab or reopening the dashboard keeps you connected without pasting it again.

GitHub does not let this website read the secret back.

The token is connected on this device, but GitHub did not confirm the cloud secret. Check Secrets: Read and write permission or retry.

Remembered tokens are kept in this browser's storage. On a shared or public computer, choose Forget token on this device and revoke the token on GitHub.

Administrator account

Change the administrator username and password used to sign in to this website.

Saving commits a new random salt and its SHA-256 digest to assets/js/config.js on GitHub. The passwords themselves are never written to a file, a commit or a browser store — only the digest. The change works on this device immediately, and on every other device once GitHub Pages finishes deploying.

Passwords must be at least 8 characters. Only the hash is stored, so a forgotten password cannot be recovered from the website — use this section again while you can still sign in, or edit assets/js/config.js in GitHub.

Abacus counters

The site visitor total and each file's download total are counted live by Abacus. GitHub Actions automatically snapshots both totals to stats/downloads.json every 15 minutes and when published files change; no visitor token is needed. The dashboard button can also save an immediate snapshot using the connected admin token. If Abacus is unreachable, the site uses the GitHub record, then this browser's local fallback.
